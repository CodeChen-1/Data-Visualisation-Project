Data handling & processing

The original files were processed to create Final_Dataset.csv. The main steps include:

  • Standardising column names and formats
  • Filtering invalid entries
  • Aggregating by year, jurisdiction and age
  • Computing summary metrics for the dashboard

Final dataset columns

  • YEAR
  • JURISDICTION
  • AGE_GROUP
  • Speeding_Fines
  • Total_Tests
  • Cannabis_Positive, Cocaine_Positive, Meth_Positive
